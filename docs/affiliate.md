# Module Affiliation & Conformité

## Conformité Creator Collective & Etsy Affiliate
1. **Zéro conversion artificielle** : Les clics traqués sont anonymisés (hash IP/User-Agent).
2. **Distinction Clics vs Commissions** : Un clic traqué ne présume pas d'une vente ou d'une commission.
3. **Respect des règles d'attribution** : Les liens utilisent les paramètres d'affiliation officiels sans redirection masquée trompeuse.
